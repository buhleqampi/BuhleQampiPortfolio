Shukuma (PWA)

This application is a delivery management tool called Shukuma, that allows customers to view and purchase products. Allows a business to track down its orders and keep analytics. And also entails a driver side, where a record of orders is kept and a driver can be assigned.

CookBook API

This is a digital cookbook created for the sole purpose to manage recipes digitally. The user can store recipes, add recipes, sort recipes, filter recipes and also has a text-to-speech feature that makes the user experience much easier.
